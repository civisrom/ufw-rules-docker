# MaxMind GeoLite2 Databases

Эта директория содержит распакованные MaxMind GeoLite2 базы данных в формате CSV.

## Структура

```
maxmind-data/
├── GeoLite2-ASN-CSV/           # ASN база данных
│   └── GeoLite2-ASN-CSV_*/
│       └── *.csv
├── GeoLite2-Country-CSV/       # Country база данных
│   └── GeoLite2-Country-CSV_*/
│       └── *.csv
├── GeoLite2-City-CSV/          # City база данных
│   └── GeoLite2-City-CSV_*/
│       └── *.csv
└── .metadata/                  # Метаданные для проверки актуальности
    ├── asn-etag.txt
    ├── country-etag.txt
    └── city-etag.txt
```

## Обновление баз

Базы данных автоматически обновляются при запуске `generate-ips.sh`:

1. Скрипт проверяет существующие базы через HTTP HEAD запрос
2. Сравнивает ETag (метку версии) с сохраненной
3. Если база изменилась - скачивает новую версию
4. Если база актуальна - использует существующую

## Ручное обновление

Для принудительного обновления баз:

```bash
rm -rf maxmind-data/.metadata
./generate-ips.sh
```

## Размер баз

Приблизительные размеры распакованных баз:

- **GeoLite2-ASN-CSV**: ~15-20 MB
- **GeoLite2-Country-CSV**: ~80-100 MB
- **GeoLite2-City-CSV**: ~300-400 MB

**Общий размер**: ~400-500 MB

## Версионирование

Базы данных включены в git репозиторий для:

- ✅ Ускорения CI/CD (не нужно скачивать каждый раз)
- ✅ Работы оффлайн
- ✅ Воспроизводимости результатов

MaxMind обновляет базы **еженедельно** (каждый вторник).

## Игнорирование

ZIP архивы временно создаются при скачивании, но автоматически удаляются и добавлены в `.gitignore`.
